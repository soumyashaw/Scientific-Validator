# Roadmap

The 0.1.x line will focus on correctness and report compatibility. Proposed
extensions are not current capabilities.

- Add optional Parquet and HDF5 reader packages without increasing core install
  weight.
- Add a separately installed ROOT reader.
- Add JUnit XML output for CI systems.
- Add signed manifests and richer metadata comparison.
- Add an explicitly approximate global uniqueness rule for very large datasets.
- Add baseline-distribution comparisons, warning by default.
- Add trusted-local-code rule plugins with an explicit opt-in security model.
- Add a draft-contract profiler that proposes but never silently adopts rules.
